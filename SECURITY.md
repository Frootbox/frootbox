# Security

Please report a vulnerability privately, never in a public issue or
discussion: use
[Report a vulnerability](https://github.com/Frootbox/frootbox/security/advisories/new)
on GitHub. Describe what an attacker can do, the version
(`php bin/frootbox about`) and the steps to reproduce it.

You get an answer within a week. A fix goes into a new version as soon
as possible, with a note in [`CHANGELOG.md`](CHANGELOG.md) under
"Security".

## Supported versions

During the developer preview only the latest `0.x` version gets fixes.
